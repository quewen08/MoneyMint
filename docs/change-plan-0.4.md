# FamBean 0.4.0 更改方案（草案）

> 参考：蜜蜂记账 BeeCount（beecount.youths.cc）的成熟交互文档（2026-08-20 二次对照全站功能目录后增补 §5A，并确认预算/周期记账推 0.5）。
> 基线：0.3.0 已完成「分类体系 / 账户视觉字段 / 交易标签 / 简化记一笔 / 账户·分类编辑弹窗 / 分类页 / PC 报表（试算平衡表 + 文字分类汇总 + 迷你柱状）」。
> 状态：核心决策已与老板二次确认（2026-08-20），供拆子任务。落地后同步更新 `CHANGELOG.md`（`## [0.4.0]`）。

## 0. 核心决策（已与老板确认）

| 项 | 决策 |
|---|---|
| 范围 | 三大块全纳入 0.4：①统计可视化 ②账户/分类增强 ③移动端账单·资产首页；另加低成本协作/检索增强（§5，2026-08-20 二次评审确认） |
| 图表 | 引入 `fl_chart`，统一封装到 `widgets/charts.dart` |
| 删除语义 | 删除分类/账户 = Beancount **close**（置 `close_date`，保留历史交易）；默认视图隐藏已关闭项，提供「显示已关闭」筛选。**已确认保留在 0.4，作为首个子迭代（R1 排雷）** |
| 默认账户 | 纯前端 `localStorage` 记忆（按类型默认 + 上次选择），零后端改动 |
| "谁记的" + 搜索 | 纳入 0.4（低成本、家庭共享价值高）；**预算 / 周期记账 / 键盘四则运算 / 每月起始日均推 0.5 候选池** |

## 1. 主题

体验闭环版：把 0.3 搭好的账芯与数据层，补成「普通人每天好用」的闭环——
可看（统计可视化）、可管（默认账户 / 账户详情 / 分类排序 / 关闭而非删）、
移动端好用（账单首页 + 月历 + 资产页），且全程不破坏 Beancount 可导出、可审计的底座。

## 2. 一、统计可视化（fl_chart）

### 2.1 图表基础组件
- 新增 `frontend/lib/widgets/charts.dart`，基于 `fl_chart` 封装三个轻量组件：
  - `PieShare`：分类占比饼图（中心显示总额，右侧/下方图例，扇区用账芯配色）。
  - `TrendLine`：收支趋势折线（支持「收入/支出双线」「净资产单线」两种模式，可切币种）。
  - `RankBar`：分类排行条（保留现有文字排行，增强为「名称 + 占比条 + 金额」）。
- 复用 `AppTheme` 配色；金额一律 `Decimal` 计算、`fontFeatures: tabularFigures()` 对齐。

### 2.2 报表页升级（`screens/reports/reports_screen.dart`）
- **核心指标卡**：净资产 / 总资产 / 总负债 / 本月收支（保留，样式统一为卡片网格）。
- **支出分类占比**：`PieShare` 饼图 + 图例（替代现文字列表），点扇区下钻到该分类流水。
- **收支趋势**：`TrendLine` 按月「收入/支出」双线（替代现 `MiniBars` 单币种柱状）。
- **分类排行**：`RankBar` 列表（Top N，可切支出/收入）。
- **资产趋势（新增）**：净资产按月 `TrendLine`。
- **时间筛选（新增）**：周 / 月 / 年 切换；左右切换时间段；筛选口径贯穿上述所有图。

### 2.3 首页 PC 增强（`screens/dashboard/dashboard_screen.dart`）
- Hero 卡片组：净资产 / 总资产 / 总负债 / 本月收支（四宫格，复用 `reports` 指标卡）。
- 近 12 月趋势迷你图（`TrendLine` 小图，置于净资产卡下方或独立卡）。
- 移动端首页见 §4，不在本页改版。

> 验收：`bean-check` 导出不受影响（图表纯前端）。fl_chart 引入后复核 Web 包体（见 §7 风险）。

## 3. 二、账户与分类增强

### 3.1 删除语义升级为 close（**最大改动点，建议先行子迭代**）
- **后端**：
  - 迁移 `006`：`accounts` 已有 `close_date`；将 `DELETE /api/accounts/{uuid}` 从「软删 `deleted_at` + 连带删引用交易」改为「置 `close_date` 关闭，保留全部交易引用」。
  - `sync_log` 新增 `op=close`（或复用 `op=update` 更新 `close_date`）；前端据此同步关闭态。
  - 旧库兼容：迁移把历史 `deleted_at IS NOT NULL` 的账户转写为 `close_date`（保留其交易）；旧 `op=delete` 日志不影响（已推送端已是关闭态表现）。
  - 余额/导出：已关闭资产/负债仍计入净资产总额（Beancount close 不抹除历史）；导出仍写 `close` 指令，过 `bean-check`。
- **前端**：
  - 删除确认弹窗文案改为「关闭后历史保留，可在筛选中查看」。
  - 账户/分类列表默认隐藏已关闭项；提供「显示已关闭」开关（`AccountsScreen` / `CategoriesScreen` 顶栏 Toggle）。
  - 已关闭项视觉降权（灰字 + 「已关闭」标签），不可再记账选入。

### 3.2 默认账户（纯前端记忆）
- `localStorage` 存 `defaultAccount: {expense: uuid, income: uuid, transferOut?, transferIn?}`，缺省按「上次记账选择」回写。
- 简化记一笔弹窗（`record_dialog.dart` / `record_screen.dart`）：支出/收入/转账按类型预选默认账户，可手动改。
- 账户行菜单新增「设为默认支出/收入账户」；设置页可查看/清除默认。
- 零后端改动。

### 3.3 账户详情页（新增 `screens/accounts/account_detail_screen.dart`）
- 入口：账户行点击 → 进详情（替代现「查看流水」直跳列表）。
- 内容：账户余额卡 + 该账户收支明细（复用 `TransactionsScreen` 按 `filterAccountUuid`）+ 该账户月度收支小图（`TrendLine`）。
- 详情页提供「查看全部流水」「设为默认」「关闭账户」入口。

### 3.4 分类拖拽排序（新增）
- `screens/categories/categories_screen.dart`：长按拖拽重排（`ReorderableListView`）。
- 排序持久化：新增 `accounts.sort_order`（整数）字段（迁移 `007`），后端存储 + 同步；BeeCount 排序为个人偏好，这里做成账本级一致。
- 仅对 `Expenses` / `Income` 类型下的二级分类排序；一级分类顺序由 seed 决定。

## 5A. 五、协作与检索增强（0.4 新增，低成本）

> 参考 BeeCount 共享账本「每条交易标记谁记的/谁编辑的」与 Web 端交易搜索。

### 5A.1 "谁记的"标记
- **现状**：`transactions.created_by` 已入库（`domain/models.go:72`，0 表示离线 push 无创建者），但读取端不返回、前端无 `createdBy` 字段。
- **后端**：
  - `GET /api/transactions` 与 `sync/pull` 的交易结构新增 `created_by_name`（repository JOIN `users.display_name`；`created_by=0` 回空串）。
  - `POST /api/transactions` / `sync/push` 创建交易时由服务端按当前 token 用户填 `created_by`，**不信任客户端传值**。
- **前端**：
  - `LocalTxn` 增 `createdByName`；pull 合并时写入，本地新建交易回填当前用户 display_name（UI 即时可见）。
  - 流水列表行尾/详情弹窗显示记账人（小字灰色，如「Alice 记」）；仅多人账本有感知，单人账本自然弱化显示。
- 导出不受影响（`created_by` 不参与 beancount 文本）。

### 5A.2 交易搜索
- 流水页顶部搜索框：按**描述关键词 / 标签 / 账户名 / 金额字符串**前端过滤，与现有筛选（账户/日期/标签/含已关闭）叠加生效。
- 家庭账本数据量级下纯前端过滤足够，不做后端搜索端点。
- 搜索结果保留筛选态；清空搜索恢复。

## 6. 不在 0.4 范围（保持占位/下期，0.5 候选池）

- **预算**（月度分类预算 + 超支提醒，需新表+迁移+预算设置页）——BeeCount 主打，0.5 优先候选。
- **周期记账**（房租/工资定期自动生成，需模板+到期生成机制，与离线同步协议有交互）——0.5。
- 键盘四则运算（+−×÷，AA 分摊场景）、每月起始日自定义（发薪日周期）——小增强，0.5 顺手做。
- 实物凭证图片/拍照（无原生客户端，Web 上传可下期）。
- 跨币种 cost 注解换算（P0 单币种约束，需 `postings` 加 cost 字段）。
- 商品/价格 CRUD（`commodities` 表仅导出引用）。
- OFX/CSV 自动导入、规则引擎、小票 OCR、年度分享海报、AI 助手/MCP。
- Postgres 横向扩展。
