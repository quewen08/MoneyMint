设计注解

移动端定位：轻量查看 + 快速记账。仅保留 5 个页面：登录、首页（净值+近期交易+最近流水）、记一笔、流水浏览/详情、基础设置。底部 Tab 从 4 个减为 3 个（首页 / 流水 / 我的），去除「账户」Tab。
移动端 · 首页简化版仪表盘：净资产大字号 + 资产分组 + 最近 2-3 条交易。不展示负债/权益分组（减少滚动），点交易可跳详情。
移动端 · 记一笔核心功能保留：日期+摘要+借贷分录+平衡指示器+保存。断网可保存本地。简化但完整，满足日常快速记账。
移动端 · 设置仅保留：同步状态卡、导出 Beancount、主题、关于、退出登录。「账户管理」「成员管理」入口标注"前往 PC 端"，点击跳转提示页。
移动端 · 移除移除：账户 CRUD、成员管理、商品/价格管理、导入功能、报表分析、高级同步日志、批量交易操作、冲正交易入口。交易详情标注"如需更正请在 PC 端操作"。
PC 端定位：完整管理 + 复杂操作。侧边栏 9 个功能模块：仪表盘、交易流水、账户管理、成员管理、商品与价格、导入与导出、报表分析、同步管理、设置。
PC · 仪表盘完整概览：4 指标卡（净值/月支出/月收入/待同步）+ 净值趋势图 + 账户余额表 + 最近交易表。比移动端信息密度更高。
PC · 账户管理完整 CRUD：表格展示所有账户（含类型筛选+搜索）、新建/编辑表单（名称/类型/开户日期/币种限制/备注）、关闭账户操作。移动端无此功能。
PC · 成员管理家庭共享核心：邀请成员、角色分配（owner/editor/viewer）、移除成员。角色说明卡。移动端仅显示"即将上线"占位。
PC · 商品与价格多币种/商品支持：商品列表（代码/名称/精度）+ 价格记录表（商品/货币/日期/汇率/来源）。为后续多币种记账和外币资产估值做基础。
PC · 导入导出导出：Beancount(.beancount) / CSV / SQLite 备份。导入：OFX/CSV/XLSX 拖放上传 + 导入历史。移动端仅保留 Beancount 导出。
PC · 报表月度收支趋势图 + 支出分类表 + 资产负债表（Trial Balance）。支持导出 PDF/CSV。移动端无此功能。
PC · 同步管理完整同步面板：状态总览 + 客户端检查点表 + 同步日志（终端风格，含 PULL/PUSH/MERGE/WARN）。移动端仅显示同步状态卡+立即同步按钮。
PC · 交易流水完整表格：日期/摘要/标记/分录/金额/创建人/操作。支持批量选择、高级筛选、冲正入口。比移动端多了批量操作和冲正功能。
PC · 记一笔增强版：标记选择（*/!）、保存并继续按钮、更宽的表单布局。功能与移动端一致但操作空间更大。
PC · 交易详情完整只读详情：含 UUID、版本号、创建人。冲正操作入口（新增反向交易）。移动端标注"请在 PC 端操作"。
规范基线主色 #3B6EF6 / 成功 #2BA471 / 警示 #E8590C；圆角 12–16；金额用等宽数字对齐。PC 侧边栏深色 #1E2330。详见 design-spec.md §6。
响应式Flutter Web (PWA) 自适应：>1024px 展示 PC 布局（侧边栏+主区）；<768px 展示移动布局（底栏+卡片）。中间宽度自动降级。
技术约束导出 .beancount 必须过 bean-check。冲正=新增反向交易而非修改原交易（不可变原则）。同步遵循 append-only + 水位增量协议。
灰色占位块 = 设计稿中的真实组件/内容。
移动端：点击手机内任意可点元素可跳转。底部 3 Tab：首页 / 流水 / 我的。
PC 端：点击左侧侧边栏导航切换页面。顶栏右侧有「记一笔」快捷入口。
